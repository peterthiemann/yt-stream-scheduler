# schedule-stream by Peter Thiemann

`schedule-stream` is a macOS command-line tool for scheduling unlisted YouTube Live broadcasts. It finds the next available Tuesday or Wednesday slot in the Europe/Berlin time zone and connects the broadcast to the reusable encoder stream from a template you choose.

The tool requests Google authorization to verify your YouTube channel, read the upcoming broadcasts and template settings, and create and bind a broadcast when you run a scheduling command. Setup is stored on your Mac. The app reads current YouTube metadata on each run and keeps it in memory for that run.

[Read the installation and setup instructions on GitHub](https://github.com/peterthiemann/yt-stream-scheduler#install-on-macos)
